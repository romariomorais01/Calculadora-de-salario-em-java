# Calculadora-de-salario-em-java
Este programa em Java calcula o salário líquido a ser transferido para um funcionário com base no valor bruto do salário e no adicional de benefícios. O cálculo considera alíquotas de imposto progressivas conforme a faixa salarial. Os valores são lidos via entrada padrão e o resultado é exibido formatado com duas casas decimais.
